The module is a flat collection of independent CLI utilities with no shared code or imports between files. `color_picker.py` and `coordinate_finder.py` are OpenCV-based interactive tools that load an image via `cv2.imread`, register mouse callbacks (`setMouseCallback`) to capture BGR values at click points or rectangle crop boxes, and print ready-to-paste configuration snippets. `debug_text_events.py` and `debug_text_events_plumber.py` are parallel implementations of the same task — parsing 'Student Console Events' from PDFs using PyMuPDF (`fitz`) and pdfplumber respectively — extracting time-stamped metric lines via regex, sorting by timestamp, and writing per-metric CSV plus matplotlib PNG plots. `setup_database.py` is a bootstrap script that deletes any existing `database/titan.db`, then runs `executescript` against `database/schema.sql` to recreate the schema. Each file is self-contained and intended to be executed directly via `python <script>.py`.

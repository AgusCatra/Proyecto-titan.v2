The module is a flat collection of independent, executable Python scripts (no shared test harness) located at the repository root alongside `tests/test_manifest.py`. Each script targets one aspect of the `core` package: `test_extractor.py`, `test_debug.py`, `test_debug2.py`, `test_final.py`, `test_fallback.py`, and `test_plot_unknowns.py` all call `core.telemetry_extractor.extraer_telemetria_visual` on a fixed sample PDF (`data/exports/report test.pdf`) with a hardcoded duration to validate extraction; `test_mapper.py` chains the extractor output through `core.graph_mapper.map_graphs`; `test_grafico.py` is a self-contained OpenCV-based calibration diagnostic that crops screenshots, applies a legend mask, thresholds by BGR color, and plots raw vs. calibrated data; `tests/test_manifest.py` validates the CSV manifest structure and checks that referenced PDFs exist under `data/reports`, then inspects the SQLite database schema in `database/titan.db` for the `perfil_operador` column. There are no imports between these scripts — each runs independently via `python <script>`.

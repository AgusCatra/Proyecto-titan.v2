The project is organized into four cooperating packages: `core` performs the shared ETL (PDF parsing via pdfminer/pdfplumber/PyMuPDF), signal extraction, behavior analysis, and report generation; `entry_scripts` exposes CLI and interactive entry points that orchestrate those core pipelines for training, reporting, and live dashboards; `utilities` provides one-off helpers (image region selection, SQLite init, debug extractors) that reuse core's parsers without being part of the main pipeline; `tests` runs the same extraction routines against sample PDFs to validate schema and plots. Cross-cutting configuration lives at the repo root — `manifest.csv` declares which PDFs belong to which labeled operator profile and exercise, and `mapeo.json` maps internal graph identifiers to human-readable signal names — so all children consume the same ground-truth metadata rather than hard-coding labels or chart titles.

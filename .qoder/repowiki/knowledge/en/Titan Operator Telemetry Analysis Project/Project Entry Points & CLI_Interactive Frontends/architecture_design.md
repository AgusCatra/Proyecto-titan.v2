This leaf module exposes five independent entry points, each targeting a different runtime: `main.py` is a batch ETL script driven by `manifest.csv` that iterates rows, skips already-processed PDFs via `core.db_manager.check_if_file_processed`, parses PDFs with `core.pdf_parser.parse_pdf_report`, runs an ML classification to assign `perfil_operador`, persists sessions/events/telemetry through `core.db_manager`, and prints a summary. `app.py` builds a customtkinter desktop application (`TitanApp`) composed of themed widgets (`Header`, `ControlCard`, `ResultsArea`, `StatusBar`, `Tooltip`, `Toast`, `LoadingOverlay`) that orchestrates single-report processing, two-report evolution comparison, telemetry graph rendering, and PDF export — all backed by the same `core.*` modules and a persisted SQLite DB at `database/titan.db`. `streamlit_app.py` provides a browser-based equivalent using `st.file_uploader`, temporary files, and `matplotlib` dark-themed plots, reusing `_procesar_y_obtener_id` logic plus `core.graph_mapper.map_graphs` for telemetry name normalization. `entrenador_ia.py` is a standalone training pipeline: it reads `Sesiones` and `ResumenEventos` from SQLite, pivots event rows into wide feature columns (`conteo_eventos_<Type>`, `penalizaciones_<Type>`), trains a `sklearn.ensemble.RandomForestClassifier` with balanced class weights, evaluates accuracy/classification report, and serializes the model to `models/modelo_clasificador.joblib`. `analisis_mvp.py` is a reporting script that joins session/event tables, aggregates per `perfil_operador`, and formats a human-readable comparison with auto-generated insights. Dependency direction is strictly outward: these scripts import from `core.*` (pdf_parser, db_manager, reporter, behavior_analyzer, plotter, etc.) but are never imported by other packages; they depend on file paths relative to their own location (`project_root = os.path.dirname(os.path.abspath(__file__))`).

`python main.py` runs the manifest-driven ETL against `manifest.csv` and `database/titan.db`; `python entrenador_ia.py` trains and saves `models/modelo_clasificador.joblib` from existing DB data; `python streamlit_app.py` launches the Streamlit server; `python analisis_mvp.py` prints a comparative profile report; `python app.py` starts the customtkinter desktop client. All scripts expect `database/titan.db` to exist beforehand (created by `setup_database.py` referenced in `main.py`).
